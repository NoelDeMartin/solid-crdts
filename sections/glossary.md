## Glossary

<dl>
  <dt><dfn data-lt="CRDT">CRDT</dfn></dt>
  <dd>
    Conflict-free Replicated Data Type: a data structure used to describe changes in distributed systems without conflicts. Learn more about them in the local-first essay [[?LOCAL-FIRST]].
  </dd>
  <dt><dfn data-lt="local-first">Local-first</dfn></dt>
  <dd>
    A software architecture that allows building apps that work offline and synchronize changes in the background. Learn more about it in the local-first essay [[?LOCAL-FIRST]].
  </dd>
</dl>
